# Full Stack E-Commerce Website

A full-stack e-commerce web application built using HTML, CSS, JavaScript, PHP, and MySQL.

## Project Overview

This project is a full-stack e-commerce website where users can register, login, view products, add products to cart, update cart quantity, proceed to checkout, and place an order.

It also includes an admin panel where the admin can login and manage products by adding, editing, and deleting product details.

## Features

- User registration and login
- Product listing
- Add to cart functionality
- Update cart quantity
- Remove products from cart
- Checkout page
- Order success page
- Admin login
- Admin dashboard
- Add new products
- Edit existing products
- Delete products
- MySQL database integration

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## How to Run This Project

1. Install XAMPP.

2. Start Apache and MySQL from the XAMPP Control Panel.

3. Copy the project folder into the XAMPP `htdocs` folder:

```text
C:\xampp\htdocs\ecommerce
```

4. Open phpMyAdmin in your browser:

```text
http://localhost/phpmyadmin/
```

5. Create a new database named:

```text
ecommerce
```

6. Import the `database.sql` file into the `ecommerce` database.

7. Open the project in your browser:

```text
http://localhost/ecommerce/
```
